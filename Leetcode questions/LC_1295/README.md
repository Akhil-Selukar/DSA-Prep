**Topics** - Array, 1D Array, Looping over array

**Interview tips** - 
In question on leetcode the constraints are given, but before starting this question one can ask below questions to the interviewer
to determine edge cases.
(To check why these questions are important and how to handle these edge cases please refer comments in code.)
1. Can array size be 0? or can there be any empty array given to the code?
2. Can there be any negative number present in given array?
