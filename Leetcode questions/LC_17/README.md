**Intuition** -
Here we are asked to get all the possible combinations of letters generated by pressing given key son mobile keypad.
So it is clear that we are asked to print the permutations of letters generated by pressing given keys. Whenever either 
permutations or combinations are asked we can use recursion (processed string and unprocessed string approach where we take 
every possibility of one letter and then add all possibilities of another letters in it recursively.)
