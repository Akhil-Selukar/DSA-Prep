### Dynamic custom stack implementation

This code and the [Custom stack implementation](https://github.com/Akhil-Selukar/DSA-Prep/tree/master/Custom%20stack/Custom%20stack%20implementation)
differs in only one thing which is the push method. In above code stack size is fixed and hence after inserting some elements
stack will be full. But the in this code instead of being full stack will increase it's size on it's own, and will never 
be full.
