### Find Nth magic number

You are given with a number N, you have to print Nth magic number.<br>
The magic number is generated using below process.
1. Convert given number in Binary form.
2. Start multiplying with 5<sup>1</sup> from LSB to MSB and calculate the value

Ex:
Input: N = 1<br>
Output: 5<br>
Binary for 1 is `1` only and 1x5<sup>1</sup> is 5.

Input: 3<br>
Output: 30<br>
Binary for 3 is `11` and 1x5<sup>2</sup> + 1x5<sup>1</sup> is 30
