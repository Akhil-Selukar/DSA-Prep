### Floor of a number

Given a sorted integer array of n elements and a target. Find the index of the largest number which is less than or equal
to target. 

Example 1:<br>
arr = {1,2,3,6,8,9,12,16,19}<br>
target = 3

output = 2<br>
Explanation: as the given target is present itself hence the largest number less than or **equal to** target is target itself.
So index of 3 is 2.

Example 2:<br>
arr = {1,2,3,6,8,9,12,16,19}<br>
target = 7

output = 3<br>
Explanation: as the given target is 7 so largest number present in array which is less than 7 is 6, and index of it is 3.
