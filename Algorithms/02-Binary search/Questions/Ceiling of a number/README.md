### Ceiling of a number

Given a sorted integer array of n elements and a target. Find the index of the smallest number which is greater than or equal
to target.

Example 1:<br>
arr = {1,2,3,6,8,9,12,16,19}<br>
target = 3

output = 2<br>
Explanation: as the given target is present itself hence the smallest number greater than or **equal to** target is target itself.
So index of 3 is 2.

Example 2:<br>
arr = {1,2,3,6,8,9,12,16,19}<br>
target = 7

output = 4<br>
Explanation: as the given target is 7 so the smallest number present in array which is greater than 7 is 8, and index of it is 4.
