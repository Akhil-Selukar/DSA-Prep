### Selection sort

Selection sort as name suggest select a particular element from given array and put that element at correct index.
That means first let's say it will select the largest element from given array and put it at the end of given array, then
repeat the same process for remaining array i.e. array from index 0 to N-1.

The time complexity for selection sort is O(N<sup>2</sup>)<br>
This algorithm is not a stable algorithm (i.e. in case of duplicate values it will not maintain the original order)<br>
This algorithm is good when the size of array or list is small.
