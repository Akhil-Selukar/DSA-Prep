### Custom LinkedList

Here in this section we have created a custom LinkedList to understand the internal working of LinkedList.

As we know that the LinkedList does not store element in consecutive memory locations hence to keep track of the list each 
element must have reference to the next element. Also the start of the LinkedList is (i.e. the first element) is considered 
as head and the last element is considered as the tail.<br>
Hence we can say that each element or each place in LinkedList has information about two things, first is the value at that 
place and second is the next node's reference.
