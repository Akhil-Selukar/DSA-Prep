### Binary search tree

Binary search tree is an ordered binary tree where all nodes smaller that a specific node will lie on left hand side of that node
and all nodes greater than that node will lie on right hand side of that node.

![Binary search tree](https://github.com/Akhil-Selukar/DSA-Prep/blob/master/Trees/Images/Binary%20search%20tree.jpg)

In above diagram if we observe for any node left nodes are smaller nodes and right nodes are greater nodes.
